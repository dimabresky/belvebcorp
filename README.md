# belvebcorp

Корпоративный портал банковской системы **belveb**. Проект работает на **1С-Битрикс: Управление сайтом** (Bitrix Framework), редакция **«Стандарт»**, ядро **≥ 26.800.0**.

Репозиторий хранит кастомный код сайта из каталога `local/`: шаблон, обработчики, компоненты и локальные модули. Ядро Bitrix, обновления и секреты стенда в репозиторий не входят.

Правила разработки — в [AGENTS.md](AGENTS.md).

## Стек

- 1С-Битрикс: Управление сайтом, редакция «Стандарт»
- Bitrix Framework, API ядра D7 (`Bitrix\Main` и модули ядра)
- PHP

## Что лежит в репозитории

| Путь | Назначение |
|------|------------|
| `templates/belvebcorp/` | Шаблон сайта |
| `php_interface/` | События, сервисы, агенты, константы |
| `components/` | Свои компоненты |
| `modules/` | Локальные модули со своей установкой |
| `ajax/` | Точечные AJAX-эндпоинты |
| `tools/` | Разовые скрипты и миграции |

## Ветки

| Ветка | Роль |
|-------|------|
| `main` | Стабильная ветка |
| `dev` | Интеграция изменений |

Изменение начинается с ветки от `dev` (`feat/…`, `fix/…`, `docs/…`). В `dev` и `main` код попадает только через pull request: рабочая ветка → `dev` → `main`.
